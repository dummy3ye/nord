# Wallpapers

Nord wallpapers, organized by resolution.

```
wallpapers/
├── 1920x1080/
├── 2560x1440/
├── 3840x2160/   (4K)
└── phone/       (portrait / ultrawide)
```

## Naming

`nord-<description>-<W>x<H>.<ext>` — e.g. `nord-aurora-valley-1920x1080.png`.

## Adding one

- Drop the file into the right resolution folder.
- If the wallpaper isn't original, note the source and license here so it stays legal to redistribute.
